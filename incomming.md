# Incoming

A quick inbox for dropping new artists, members, producers, or studios into the vault. Add a plain name under the matching section below — one per line, no formatting, batch stamps, or research required. That's the AI agent's job once the entry is processed.

When told to **"handle incomming,"** entries are worked one at a time, in this order: `## Artists` first, then `## Members`, then `## Producers`. Processing always **stops before `## Studios`** — the agent asks for confirmation before touching that section. See `about.md` → *Handling incomming.md* for the full procedure.

Once an entry has been fully processed through its workflow, remove its line from this file. If an entry already has a page in the vault, that means the page needs updating, not skipping — run the workflow against the existing page to refresh it, then remove the line.
